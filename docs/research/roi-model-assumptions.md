# ROI model guardrails

- Returned staff time is capacity until the user explicitly assigns a value-capture percentage.
- Human review and exception fallback reduce the time benefit before labor value is calculated.
- Error reduction is a separate value stream and may be zero when the cost cannot be defended.
- Build cost and recurring software/maintenance cost are both included.
- A conservative stress case must not improve the expected economics.
- Strong economics cannot override an unstable process, a guessed baseline, or a high-impact need for piloting.
- A positive ROI result does not select the automation platform; architecture remains a separate decision.
- Currency selection is a display/accounting unit only. This tool does not perform FX conversion.
